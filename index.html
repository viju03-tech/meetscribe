Privacy & settings

MeetScribe is designed so your meetings never leave this device.

100% local processing

Transcription uses your browser's own built-in speech recognition, and the summary, decisions, action items and Q&A are all computed by code running in this page. There is no MeetScribe server and no account.

No cloud AI

Cloud processing is not used. Your audio and transcripts are never sent to a cloud AI service, an analytics platform, or any third party by this app.

What is stored

Meeting titles, transcripts and speaker names are saved in this browser's local storage so your history survives a reload. Audio is not stored — recordings and uploads are kept only in memory for the current session.

Your controls

Delete any meeting from the dashboard and it is removed from local storage immediately. Clearing your browser's site data removes everything MeetScribe has saved.
